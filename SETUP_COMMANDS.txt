================================================================================
                        TROUBLESHOOTING
================================================================================

PROBLEM: "Posts not loading"
SOLUTION:
  1. Check Supabase > Tables > verify "posts" table exists
  2. Run 001_schema.sql migration again
  3. Refresh browser (Ctrl+R)

PROBLEM: "Can't upload images"
SOLUTION:
  1. Check Supabase > Storage > verify 3 buckets exist
  2. Verify each bucket is "Public"
  3. Verify policies added to each bucket
  4. Open browser console (F12) for error messages

PROBLEM: "Can't follow users"
SOLUTION:
  1. Check Supabase > Tables > verify "follows" table exists
  2. Check Supabase > Tables > profiles > ensure users exist
  3. Refresh page and try again

PROBLEM: "App won't start"
SOLUTION:
  cd Frontend
  npm install
  npm run dev

PROBLEM: Other errors
SOLUTION:
  1. Open browser console (Press F12)
  2. Look for red error messages
  3. Check FUNCTIONAL_TESTING_GUIDE.md Troubleshooting section
  4. Check Supabase dashboard for status
