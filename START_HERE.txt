================================================================================
                      5-MINUTE QUICK START
================================================================================

1. Create Supabase Project
   - Go to supabase.com
   - Click "New Project"
   - Create project named "cozmeet"
   - Copy Project URL and API Key

2. Run Database Migrations
   - Go to Supabase SQL Editor
   - Run: Backend/migrations/001_schema.sql
   - Run: Backend/migrations/002_rls.sql
   - Run: Backend/migrations/003_seed.sql

3. Create Storage Buckets
   - Go to Storage in Supabase
   - Create 3 public buckets:
     * avatars
     * covers
     * post-images

4. Start Frontend
   cd Frontend
   npm install
   npm run dev

5. Configure Environment
   - Edit Frontend/.env with your Supabase credentials
   - Refresh browser
   - Done!
